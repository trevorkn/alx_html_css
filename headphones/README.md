# 🎧 Headphones Landing Page

Welcome to the **Headphones** landing page – a fully responsive, accessible, and beautifully designed static web page built entirely with **HTML** and **CSS**. This project is a clone of a Figma design created by [Nicolas Philippot](https://www.behance.net/nicolasphilippo), crafted to sharpen and demonstrate mastery of front-end fundamentals without using any external libraries or JavaScript.

---

## 🚀 Project Overview

This project was created as part of a hands-on exercise to solidify knowledge in:

- Semantic HTML structure
- Custom CSS styling
- Responsive web design (mobile-first)
- Accessibility best practices
- Page layout and typography
- Figma to code conversion

The final page replicates the look and feel of the original design as closely as possible.
